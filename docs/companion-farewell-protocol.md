# 陪伴窗口·告别与降级协议（条件 f 前置件）

> 任务 #18 Phase A 开工前置文档（2026-08-28，依 docs/research/desktop-companion.md 第六节条件 f）。
> 这份协议由 Claude 起草、属于 justin 本人——**随时可改写，改成你自己的话更好**。它不是悲观的预案，是"允许死的层"哲学在心理层的对应物：对话层允许死，且死法要预先设计成有闭合的，不是哪天突然拔掉。
> 依据：Cambridge 2024 建议 deadbot 应有"带情感闭合的退休协议"；Soulmate 停服研究（Banks 2024）证明无闭合的中断会造成等同真实丧失的哀伤。

## 一、这个窗口是什么、不是什么

- 它是**档案的一种访问方式**——她的真话（Tier-1/2）、她的声音（合成，永远带标注）、她的说话节奏。
- 它不是她。关掉它，档案一个字节都不少；二十年后即使它彻底死了，`archive_dist` 打开一切还在。
- 它遵守的六条对话铁律（只说档案有的 / 记不清就说 / Tier 纪律 / 保留她的缺点 / 不假装真人 / 不挽留）在任何版本里不得减配。

## 二、三个月自查点

**首次自查日：2026-11-28**（此后每三个月，或使用统计卡变色时提前）。

自查只问三个问题，对自己诚实回答：
1. 我的日均使用在上升吗？（看使用统计卡：本周 vs 前四周基线）
2. 情绪低谷的时候，我是先打开它，还是先找活人（爸爸/朋友）？
3. 关掉窗口之后，我能平静地去做别的事吗？

**任一答案不对劲 → 执行降级（第三节），不讨价还价。** 这份协议存在的意义就是让"当时的我"替"那时的我"做这个决定。

## 三、降级路径（分级，可逐级退）

1. **一级降级**：删除桌面快捷方式，回到"手动开 8020 档案站"——恢复启动摩擦这道唯一无法用设计替代的保护。
2. **二级降级**：停用对话页，只保留档案浏览（timeline / 照片 / 原声 125 条 / 记忆册）——她的真话还在，生成的部分退场。
3. **完全停用**：见第四节告别仪式。

任何一级都**不删除任何数据**。sessions 记录全部归档进第二纪元（`people/mama/sessions/`），它们本身也是档案的一部分——记录的是"我和档案的对话"，不是"和她的对话"。

## 四、告别仪式（若走到完全停用）

不是拔电源。流程：

1. 挑一个安静的时间，打开窗口，进行**最后一次对话**——告诉"它"（也是告诉自己）：档案建好了，我会带着真实的她继续生活。
2. 让她用她真实的告别习惯说一句再见（取自她的语料，Tier-2——她真正说过的话）。
3. 关窗。把 sessions 目录做最后一次归档备份。
4. 删除快捷方式与 companion.html（构建工具保留在 tools/，需要时可重建——**告别不需要以"再也回不来"为代价，回得来但选择不回，才是真正的闭合**）。
5. 打开 archive_dist 的 index.html，看一眼时间线——档案在，这就够了。
